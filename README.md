# GH Internship 2026

Spring Boot backend project.

## Stack

- Java 21
- Spring Boot 4.0.0
- Spring Web (REST API)
- Spring Data JPA
- Spring Security
- PostgreSQL
- Lombok
- Bean Validation

## Getting Started

### Prerequisites

- Java 21+
- Maven 3.9+
- PostgreSQL

### Run locally

```bash
./mvnw spring-boot:run
```

### Build

```bash
./mvnw clean package
```
